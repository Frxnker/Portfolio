# Francisco López Lobanova - Professional Portfolio

Este es el repositorio del portfolio profesional de **Francisco López Lobanova**, Especialista en IT, Administrador de Sistemas y Desarrollador Web.

El proyecto consiste en una Single Page Application (SPA) estática diseñada para mostrar experiencia, habilidades técnicas y proyectos de manera visualmente atractiva, profesional y completamente responsiva.

## 🚀 Características Principales

- **Diseño Premium**: Interfaz moderna con temática oscura (Dark Mode), uso de *glassmorphism* y gradientes sutiles para un acabado profesional.
- **Totalmente Responsivo**: Adaptable a cualquier tamaño de pantalla (Móvil, Tablet y Escritorio).
- **Animaciones Integradas**:
  - Efecto de máquina de escribir (Typewriter) en la sección Hero.
  - Aparición suave de elementos al hacer scroll (Reveal on Scroll) utilizando `IntersectionObserver`.
  - Efectos *Hover* interactivos en tarjetas y botones.
- **Menú de Navegación Móvil**: Panel de navegación superpuesto para pantallas pequeñas.
- **Rendimiento Óptimo**: Construido sin frameworks pesados, asegurando tiempos de carga rápidos.

## 🛠️ Tecnologías Utilizadas

- **Estructura**: HTML5 Semántico.
- **Estilos**: CSS3 Puro (Vanilla CSS), Flexbox, CSS Grid y variables nativas.
- **Interactividad**: JavaScript Vanilla (ES6+).
- **Tipografía**: [Google Fonts](https://fonts.google.com/) (Inter y Outfit).
- **Iconografía**: [Lucide Icons](https://lucide.dev/).

## 💻 Instalación y Despliegue

Dado que el proyecto utiliza tecnologías web estándar (HTML/CSS/JS), no requiere de ningún proceso de compilación complejo ni de la instalación de dependencias externas.

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/Frxnker/Portfolio.git
   ```
2. **Ejecución Local**:
   Simplemente abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Safari, Edge). También puedes utilizar extensiones como *Live Server* en VS Code para una mejor experiencia de desarrollo.
