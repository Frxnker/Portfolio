## 🚀 Características Principales

- **🌓 Soporte Nativo para Modo Oscuro/Claro**: La web detecta automáticamente la configuración de tu sistema (Windows, macOS, iOS, Android) y adapta su paleta de colores (`prefers-color-scheme`) para una lectura óptima.
- **✉️ Formulario de Contacto Profesional**: Integración con **FormSubmit** mediante **AJAX (Fetch API)**. Los mensajes se envían en segundo plano sin recargar la página, con estados de carga y confirmación visual.
- **🔗 Sección de Enlaces Personales**: Un apartado dedicado con tarjetas interactivas para acceder rápidamente a mis perfiles profesionales (GitHub, LinkedIn).
- **📱 100% Responsivo**: Diseño fluido que se adapta perfectamente a dispositivos móviles, tablets y monitores de alta resolución.
- **⚡ Animaciones y Micro-interacciones**:
  - Efecto de máquina de escribir dinámico.
  - Aparición suave de elementos al hacer scroll (*Reveal on Scroll*).
  - Efectos de *glassmorphism* y gradientes dinámicos.
  - Iconos SVG nativos para máxima compatibilidad y nitidez.

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML5 Semántico, CSS3 Puro (Variables, Grid, Flexbox), JavaScript Vanilla (ES6+).
- **Servicios**: [FormSubmit](https://formsubmit.co/) (Gestión de correos via AJAX).
- **Iconografía**: [Lucide Icons](https://lucide.dev/) e Iconos SVG personalizados.
- **Tipografía**: Google Fonts (Inter & Outfit).

## 💻 Instalación y Uso Local

El proyecto es estático y no requiere dependencias. 

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/Frxnker/Portfolio.git
   ```
2. **Ejecución**:
   Simplemente abre `index.html` en tu navegador o usa la extensión **Live Server** en VS Code para previsualizar los cambios en tiempo real.
